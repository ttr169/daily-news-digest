C. 能源传导链 · 原油 / 天然气 / 航运

C1. 霍尔木兹风险传导链：地缘 → 运输 → 库存 → 炼厂 → 成品油 → 价格
霍尔木兹通行受限 → 油轮绕行 / 海运费大涨 → 全球原油库存低位 → 炼厂原料成本抬升 → 化工品价格上行 → SC 原油破 900 元/桶

金联创副总裁韩景媛分析认为，霍尔木兹海峡通行受限、沙特输油管道故障、OPEC 实际减产，叠加全球原油库存低位运行、海运费大幅上涨，共同推动内盘油价快速上行；本轮油价异动的核心驱动是中东地缘局势恶化。

新浪财经报道「国内原油期货首次升破 900 元/桶，推高化工品价格」，印证了从原油到下游化工品的价格传导。

来源：新浪财经、搜狐（引金联创韩景媛）（2 源交叉）
C2. 海湾原油与非海峡原油价差走阔至 43 美元/桶
海峡通行严重受限 → 海湾原油外运受阻 → 区域价差急剧走阔 → 炼厂配方切换 → 成品油裂解价差重估

这一价差结构是判断「地缘溢价是否已充分定价」的关键观察指标。

来源：MSN 转载（单源，待确认）
