C. 能源传导链 原油 / 天然气 / 煤炭 / 航运

★★★★★传导链一：霍尔木兹袭击 → 海运保险与绕行 → 到岸成本 → 炼厂进料 → 成品油

事件：霍尔木兹海峡油轮遇袭 + 胡塞打击沙特目标 + 伊朗警告封锁范围或扩大 → 运输：波斯湾—红海航线风险溢价上升，战争险保费与绕行成本抬升（素材未给出具体费率，不作估算） → 库存：到岸节奏受扰，消费端提前补库动机增强 → 炼厂：原油进料成本与不确定性同步上升，裂解价差承压 → 成品油：柴油、汽油端价格上行压力 → 价格：布伦特突破 110 美元、WTI 逼近 100 美元

这条链条的关键节点在「运输」环节——素材中没有任何关于保费、运费指数或绕行里程的可验证数字，因此本报告不对该环节做量化，仅标注其为传导的放大器。

来源：MSN、tmgm、Pluang、金十数据（4 源交叉）

★★★★★传导链二：美国柴油紧张 → 暂缓对俄制裁 → 进口俄柴油 → 成品油价格

事件：美国柴油供应紧张，政策端暂缓部分对俄制裁 → 运输：放开俄罗斯柴油船货流向美国（具体船期与量级素材未披露） → 库存：美国馏分油库存获得边际补充 → 炼厂：美国炼厂柴油裂解价差压力缓解，但同时面临进口竞争 → 成品油：柴油价格上行斜率放缓 → 价格：对原油端形成反向缓冲（与链条一方向相反）

这条链条解释了为什么同一窗口内会出现「油价破 110」与「WTI 回落至 97 下方」两种叙事——成品油端的政策缓冲与原油端的地缘冲击在方向上是相反的。详见「数据分歧提示」。

来源：虎嗅网、央广网、凤凰网（3 源交叉）

★★★★传导链三：俄罗斯供给预期 → WTI 承压 → 与地缘溢价对冲

事件：市场对俄罗斯原油供给上升的预期升温 → 运输：俄油出口流向预期改善 → 库存：美国库存报道上升，与供给预期叠加 → 炼厂：进料选择增加 → 成品油：成本端压力缓和 → 价格：WTI 一度回落至 97 美元下方

EnergyNow 另报道「Oil Touches Pre-War Levels on Rising Middle East Supply」——即中东供给上升使油价触及战前水平，方向与地缘溢价叙事完全相反。这三条链条并存，构成本周能源定价的核心矛盾。
